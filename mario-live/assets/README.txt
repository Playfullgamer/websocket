Optional files you can drop in this folder (all optional):

  mario.glb   - a rigged Mario model to use instead of the built-in one
  luigi.glb   - a rigged Luigi model
  scene.glb   - extra scenery added to the world
  music.mp3   - quiet background music (ducks while someone talks)

Restart START.bat after adding files. Only use models/music you have the rights to stream.
